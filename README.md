# nori-linux-helpers
CLI Helpers - use with your favorite LLM

---

A pragmatic collection of zero-dependency Bash helpers built to solve real friction in daily Linux and LLM-assisted workflows.  
*Uma coleção pragmática de helpers em Bash, sem dependências externas, criada para resolver gargalos reais no fluxo diário com Linux e LLMs.*

---

## Tool 1 - Nori Paste Sh

Captures large code blocks pasted into the terminal without TTY input buffer truncation, saves them safely with timestamps, applies executable permissions, computes `SHA256`, and validates syntax via `bash -n`.

*Captura blocos grandes de código colados no terminal sem truncamento no buffer de entrada do TTY, salva com segurança usando timestamp, aplica permissão de execução, gera hash `SHA256` e valida a sintaxe com `bash -n`.*

### Why it exists / Por que existe

When pasting large scripts (>4 KB / ~60+ lines) generated by LLMs directly into terminal emulators (GNOME Terminal, Konsole, Yakuake, Tilix, or raw TTY), the Linux kernel `N_TTY` input buffer can overflow and silently truncate lines—breaking heredocs and multi-step scripts. `nori-paste-sh` reads the raw stream cleanly until `Ctrl+D` and audits the output automatically.

*Ao colar scripts grandes (acima de 4 KB / ~60 linhas) gerados por LLMs direto no terminal, o buffer `N_TTY` do kernel Linux pode estourar e truncar linhas silenciosamente, quebrando heredocs e scripts longos. O `nori-paste-sh` lê o fluxo bruto até `Ctrl+D` e audita o arquivo automaticamente.*

### Key Features / Recursos Principais

* **Zero external dependencies / Zero dependências:** Pure Bash + standard GNU coreutils (`install`, `wc`, `sha256sum`, `bash`).
* **Overwrite protection / Proteção contra sobrescrita:** Creates timestamped copies (`YYYYMMDD-HHMMSS`) by default unless `NORI_PASTE_OVERWRITE=1` is explicitly passed.
* **Automatic integrity check / Checagem automática:** Prints line/byte count, `SHA256` checksum, and runs `bash -n` syntax validation immediately after capture.
* **Self-contained lifecycle / Ciclo de vida completo:** Automatic idempotent `$PATH` setup on install and clean removal via `--uninstall`.
* **Debian 11+ compatible / Compatível com Debian 11+:** Tested across Debian, Ubuntu, Kubuntu, Mint, and Kali.

### Quick Install / Instalação Rápida

```bash
git clone https://github.com/frossardz/nori-linux-helpers.git
cd nori-linux-helpers

# User install (~/.local/bin + automatic PATH setup)
bash bash-helpers/coding/nori-paste-sh/nori-paste-sh-installer.sh
source ~/.bashrc

# Or system-wide install (/usr/local/bin)
sudo bash bash-helpers/coding/nori-paste-sh/nori-paste-sh-installer.sh --global
```

### Usage / Uso

```bash
# 1. Default capture -> saves to ~/nori-paste-YYYYMMDD-HHMMSS.sh
nori-paste-sh

# 2. Named capture -> saves to ~/bootstrap_server-YYYYMMDD-HHMMSS.sh
nori-paste-sh bootstrap_server

# 3. Relative or absolute path -> saves to the exact path (creates parent dirs)
nori-paste-sh scripts/deploy_check.sh

# 4. Explicit overwrite (bypasses timestamped copy)
NORI_PASTE_OVERWRITE=1 nori-paste-sh scripts/deploy_check.sh
```

Paste your code block into the terminal prompt and press **`Ctrl+D`** to finish, validate, and inspect.  
*Cole o bloco de código no terminal e pressione **`Ctrl+D`** para encerrar, validar e inspecionar.*

### Uninstall / Desinstalação

```bash
# Removes the binary and cleans the PATH entry added during installation
nori-paste-sh --uninstall && hash -r
```

*(Alternatively, run `bash bash-helpers/coding/nori-paste-sh/nori-paste-sh-installer.sh --uninstall` from the repository directory.)*
